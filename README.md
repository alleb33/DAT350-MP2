# COVID-19 Global Outcomes Analysis

## Overview

This project analyzes global COVID-19 country-level data to evaluate disease burden, severity, regional differences, and short-term growth trends. The goal of this analysis is to inform strategic allocation of healthcare resources based on empirical patterns in confirmed cases, deaths, recoveries, active cases, and weekly growth rates.

The project includes exploratory data analysis, metric calculation (Active Rate, Case Fatality Rate, Weekly Growth), and multiple visualizations to support data-driven recommendations.

---

## Main Research Question

**How can global COVID-19 outcome and growth patterns inform strategic allocation of healthcare resources?**

## Visualizations

This analysis includes five visualizations:

1. Global distribution of confirmed cases by outcome (Active, Recovered, Deaths)
2. Global Case Fatality Rate (CFR) by country (choropleth map)
3. Top 15 countries by active case rate
4. Average Case Fatality Rate by WHO region
5. Top 15 countries by weekly growth rate

---

## Key Findings

- Some countries maintain high active case burdens, indicating ongoing outbreak intensity.
- Case Fatality Rate varies significantly across regions.
- Certain countries show rapid weekly growth, signaling emerging hotspots.

---

## Actionable Recommendations

Based on the analysis:

1. Prioritize medical resource deployment to countries with high active case rates and rapid weekly growth.
2. Allocate critical-care support (ICU equipment, ventilators, trained personnel) to regions with elevated case fatality rates.
3. Collect additional data on hospital capacity and testing rates to improve mortality forecasting and supply planning.
